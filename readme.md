## 💼 Experience

### Software Developer · AIO Infinity

**Jan 2026  – Present** · 1 year

InfiQ: a multi-tenant WhatsApp Business messaging platform covering campaigns, a shared agent inbox, no-code chatbot flows and subscription billing.

Full-stack developer on the InfiQ platform, working across the NestJS backend and the Next.js dashboard.

- Built a fair-queueing campaign sender on BullMQ with one lane job per WhatsApp number, token buckets and tenant holds, so one tenant's bulk send cannot starve others.
- Developed a PostgreSQL wallet and ledger engine with per-tenant locks and idempotency keys, preventing double charges on retried or replayed requests.
- Integrated Razorpay with signature-verified, replayable webhooks and reconciliation jobs, keeping payments consistent through duplicate and out-of-order events.
- Secured the platform with JWT, TOTP 2FA, WebAuthn passkeys and AES-256-GCM encryption of stored WhatsApp credentials.
- Built a multi-tenant Next.js dashboard of about 140 routes with real-time live chat over Socket.IO and an offline outbox using IndexedDB and a service worker.

**Stack:** `TypeScript` `NestJS` `Next.js` `React` `PostgreSQL` `Prisma` `Redis` `BullMQ` `Socket.IO` `Docker`
